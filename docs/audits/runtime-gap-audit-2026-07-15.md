Os 3 adapters não-streaming abortam via `AbortSignal.timeout(this.timeoutMs)` (`adapters/openai.adapter.ts:114`, `gemini.adapter.ts:126`, `anthropic.adapter.ts:124`), cujo reject é um `DOMException{name:"TimeoutError"}` com `.code` **numérico `23`**. O classificador é chamado nas 2 costuras de resiliência da hot-path viva: `retry-decorator.ts:25` (dentro do catch de `withRetry`) e `circuit-breaker.ts:123` (dentro de `recordFailure`). Como `23 ?? "" === 23`, executa `(23).toUpperCase()` → **`TypeError: ...toUpperCase is not a function`**. **Cenário concreto:** OpenAI tem spike de latência e um passo ReAct do surface agent (OU uma chamada do MessageAnalyzer da pipeline — ambos via `createLLMGateway`) estoura o timeout de request. Fix trivial: `String(e.code ?? "").toUpperCase()`. `Eh≈0.25h`. **(Nota de método: minha 1ª verificação grepou o path errado (`llm/openai.adapter.ts` vs `llm/adapters/openai.adapter.ts`) e "refutou" o T2; ao corrigir o path, o T2 se confirmou integralmente.)**
